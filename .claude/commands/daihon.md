撮影済みの動画からリールの台本を書く。動画: $ARGUMENTS

## 手順

1. `docs/channel-context.md` を読む(方針の1次資料)
2. `scripts/video-sheet.sh <動画パス>` を実行し、出力されたディレクトリの
   `meta.txt` を読み、`sheet_1s.jpg` → `sheet_head.jpg` → `sheet_tail.jpg` の順に
   Read ツールで**必ず画像として見る**。推測で書かない
3. 判断がつかないカット(人物が誰か、何をしているか)は、先に質問する
4. 下記の形式で台本を出す

## 出すもの

**A. 内容の整理** — 何秒に何が映っているかの表。飼い主の意図と食い違っていたら指摘する

**B. テロップ台本** — 時間割り付き。関西弁・ムギの心の声・一人称「ボク」

| 時間 | テロップ | 狙い |
|---|---|---|

- 冒頭0〜2秒は絵の説明をしない。**続きを見る理由**だけを書く(8〜12字)
- 冒頭は動いているコマから始まっているか確認し、溜めのコマがあればカット位置を指示
- オチはツッコミか意外な結末
- CTAは1つだけ、1.8秒以上
- 人が登場する回は「誰に言っているか」をテロップで固定する

**C. キャプション案** — 本文 + CTA1つ + タグ8個(`BASE_TAGS` 6個 + 固有2個)

**D. 気づいたこと** — 尺・テロップの視認性・音量・プライバシー(顔、表札、ナンバー、
勤務中の第三者)で直すべき点があれば。無ければ「無し」と書く

## 禁止

- `docs/channel-context.md` の「2-1. 先代犬ミルクの扱い」に反する提案
- 標準語のセリフ、作り物の関西弁
- CTAを2つ以上入れること
