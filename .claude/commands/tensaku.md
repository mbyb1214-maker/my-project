テロップ入りの完成動画を、投稿前にチェックする。動画: $ARGUMENTS

## 手順

1. `docs/channel-context.md` を読む
2. `scripts/video-sheet.sh <動画パス>` を実行し、`meta.txt` と3枚のシートを
   Read ツールで**画像として見る**
3. 下のチェックリストを上から順に見て、**引っかかった項目だけ**を報告する
   問題がない項目は列挙しない(全部読ませない)

## チェックリスト

**伝わるか**
- [ ] 冒頭1秒で「続きを見る理由」が立っているか。絵の説明で終わっていないか
- [ ] 1コマ目が動いているか(溜めのコマで始まっていないか)
- [ ] 登場人物の関係が、初見の人に伝わるか。「誰に言っているか」が固定されているか
- [ ] 同じ意味のテロップが2回出ていないか
- [ ] テロップが途切れる空白区間がないか

**構成**
- [ ] オチがあるか
- [ ] CTAが1つだけか。表示1.8秒以上か
- [ ] ラストが冒頭とつながってループするか
- [ ] 止まっている絵を3秒以上見せていないか

**表記・見た目**
- [ ] 誤字(特に「ずーと」→「ずーっと」のような促音)
- [ ] 標準語が混ざっていないか。作り物の関西弁になっていないか
- [ ] 白背景でテロップが溶けていないか(黒フチ・黒帯)
- [ ] テロップの位置が上から20〜25%か(下部はUIに隠れる)

**安全**
- [ ] 家族以外の人の顔が映っていないか
- [ ] 玄関の外(表札・向かいの家・車のナンバー)が読めないか
- [ ] 勤務中の人が映る回は、本人への確認を促したか
- [ ] 音声に個人名・地名が入っていないか(※音は聞けないので、確認を促すこと)

**技術**
- [ ] 1080x1920 の縦型か
- [ ] max_volume が 0dB に近すぎないか(BGMを足すなら下げる指示)

## 報告の形

引っかかった項目を**優先順**に並べ、それぞれ「現状 → 直し方」を具体的に書く。
直せば投稿できる状態なら、最後にそう明言する。
