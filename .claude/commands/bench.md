参考アカウントを観測して記録する。対象: $ARGUMENTS

## 手順

1. `docs/benchmark.md` を読む。**そのアカウントの過去の記録があるか確認する**
2. `docs/channel-context.md` を読む(ムギミルク側の現状と方針)
3. 添付されたスクリーンショットを Read ツールで**すべて画像として見る**
4. 数字を読み取る。読めない箇所は推測せず「読み取れず」と書く
5. 分析して報告し、`docs/benchmark.md` に追記する

## 読み取るもの

**プロフィール画面から**
- アカウント名(検索キーワードが入っているか)
- フォロワー数 / フォロー中 / 投稿数
- bio の全文と、その構成(1行目が読者への呼びかけか、犬の説明か)
- ハイライトの名前と並び順
- 外部リンクの有無(収益導線)

**グリッドから**
- 各投稿のタイトルと再生数を**すべて**表にする
- サムネのデザイン(統一されているか、シリーズ名のラベルがあるか)
- **新旧で数字が跳ねている境目がないか**(グリッドは新しい順)

**個別投稿から**
- 再生 / いいね / コメント / リポスト / シェア
- 使っている音源
- 動画内テロップのスタイル(サムネと違うか)

## 分析する観点

1. **ジャンル別の再生数の構造** — どの型がホームランで、どの型が安定か
2. **跳ねた時点と、その要因** — 何を変えて数字が動いたか
3. **ムギミルクとの比較** — フォロワー数あたりの再生数、プロフィールの設計
4. **棲み分け** — そのアカウントが持っていない軸は何か
5. **真似すべきでないもの** — 数字は出るが、頻度や倫理面で慎重に扱うべき型

## 2回目以降(過去の記録がある場合)

**差分が本体です。** 必ず前回と比較する。

- フォロワー数の増減
- 新しく追加された投稿と、その再生数
- シリーズ名・サムネ・bio が変わっていないか
- 前回「次回チェックすること」に挙げた項目の答え合わせ

## 記録の書き方

`docs/benchmark.md` の末尾に追記する。既存の記録は消さない。

```
# #N @アカウント名

**観測日:YYYY年M月D日(N回目)**

## 前回からの変化
（2回目以降のみ。フォロワー・投稿・デザインの差分）

## 基本データ
（表）

## リール一覧
（表。タイトルと再生数）

## 発見
（番号付きで）

## ここから決めたアクション
（ムギミルクで実行する具体的なこと）

## 次回チェックすること
（チェックボックス）
```

## 禁止

- スクショに写っていない数字を推測で書くこと
- `docs/channel-context.md` の「2-1. 先代犬ミルクの扱い」「2-2. ムギの体のこと」に
  反するアクションを提案すること
- 悲しみや病気を数字のために使う企画を提案すること
  (先行事例がやっていても、事実として伝えるだけに留める。判断は飼い主)
