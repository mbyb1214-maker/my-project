投稿の結果を記録する。対象: $ARGUMENTS

## 手順

1. `docs/posts.md` を読む。**検証中の仮説**と過去の投稿を把握する
2. `docs/channel-context.md` の「4. コンテンツの柱」を読む(基準値)
3. 添付されたスクリーンショットを Read ツールで**すべて画像として見る**
4. 数字を読み取る。**読めないものは推測せず「未取得」と書く**
5. `docs/posts.md` の末尾に追記し、仮説の表を更新する

## 読み取るもの

**概要タブ**
- 閲覧数 / 閲覧者 / 平均再生時間 / フォロー数
- スキップ率・シェア率・いいね率・保存率・再投稿率・コメント率(**高/低/通常の判定も**)
- 再生時間のグラフ(**どこで急落したか**。暗転やCTAの位置と照合する)
- 閲覧数の上位のソース(フィード / プロフィール / リールタブ / 発見 / 検索)

**エンゲージメントタブ**
- プロフィールへのアクセス / フォロー数
- いいね・コメント・再投稿・シェア・保存の実数
- **いいねされたタイミングのグラフ**(ピークが何秒か)

**オーディエンスタブ**
- フォロワー / 非フォロワーの比率
- 年齢・性別・国

## 必ずやること

1. **仮説の表を更新する。** この投稿で検証できた仮説があれば結果を書き、
   確定したものは「確定したこと」へ移す
2. **同じ種類の過去投稿と比べる。**
   通常リールは通常リールと、トライアルはトライアルと。**種類をまたいで比べない**
3. **リーチと質を分けて評価する。**
   閲覧数が少なくても、いいね率・完走率が高ければ「質は成功」。
   この区別をしないと、良い内容をやめてしまう
4. 再生グラフの急落点を、**暗転やCTAの位置と照合する**

## 禁止

- スクショに写っていない数字を推測で埋めること
- 投稿直後の数字で結論を出すこと(数日置いた値を使う)
- 通常リールとトライアルリールの数字を直接比較すること
