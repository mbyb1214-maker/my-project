## ジャンルの役割分担(検証済み)

| ジャンル | 主な役割 | 効きやすい指標 |
|---|---|---|
| 日常系 | いいね・コメントなど即時反応 | いいね率・コメント率 |
| ケア系(圧迫排尿・介護グッズ等) | 差別化・信頼・同じ境遇の飼い主との交流 | コメント率・保存率 |
| 旅系・お店紹介 | 新規層への拡散、保存される価値 | 保存率・シェア率 |
| **健康トラブル・回復系**(過去投稿で発見、要注意ジャンル) | アカウント最大の閲覧数・コメント数を記録 | 閲覧数・コメント数 |

オーディエンスは45〜64歳が中心(複数投稿で一貫)。実用性・共感・いたわりを軸にしたトーンが合う。

## 健康トラブル・回復系(最重要の制作方針)

過去投稿「今朝から元気がなくて…」(膵炎の発症〜回復を実況)→「心配かけてごめん」の連載が、これまで検証した中で最も強い結果を出した。

**「今朝から元気がなくて…」の実測値(アカウント歴代最高)**:閲覧18,521/プロフィール訪問622/フォロー21/コメント47/リンククリック7/保存11/スキップ率36.7%(過去最高に低い=好調)。流入元はフィード54.0%中心(全力系はリールタブ+発見が中心で対照的)。投稿直後に1.3万回まで急騰しその後3週間かけて1.85万回まで伸びる「バズ」型の曲線。

**ただし転換率は全力系より低い**:プロフィール訪問→フォローの転換率3.4%(全力ぴょんぴょんは19.8%)、いいね率7.7%(低)、コメント率0.4%(低)。広く浅く拡散し本物の共感で視聴維持率は最高だが、熱心なフォロワー化の効率では全力系に劣る。**全力系=効率よく新規ファン化/健康トラブル系=圧倒的リーチと共感、ただしファン化効率は低い**、という役割分担で理解する。

**オーディエンス**:フォロワー以外89.4%(歴代最高、全力系の80%を上回る)。流入はフィード54%中心だが、これはアルゴリズムの「発見」ではなく**フォロワーの友人ネットワークを通じた社会的拡散**(いいね・コメントを見た非フォロワーに表示される)と推測される。性別は女性77.3%(歴代最高の偏り)、年齢は45-54歳35.7%・55-64歳31.5%で合計67.2%とコア層への集中度も最高。「いいねされたタイミング」のグラフは序盤と終盤の2箇所に山があり、冒頭のフックだけでなく結末(回復・安心の報告)まで見てもらって初めて真価を発揮する構成であることを示す。

**第2話「心配かけてごめん」の実測値(連載構造の効果が実証された)**:閲覧3,997(第1話の約1/5)、だが**いいね率21.1%(高、第1話は7.7%)・コメント率1.6%(高、第1話は0.4%)**と、エンゲージメント率は大幅に向上。広く浅い第1話に対し、狭く深く刺さる第2話という構図。流入元はフィード80.7%・**プロフィール6.4%(通常1〜2%程度のところ突出)**で、「また報告する」という予告を覚えてプロフィールを直接見に来た人が多かったことを示す。構成は「心配かけてごめん」(謝罪)→「膵炎って診断されたけど、ゆっくり寝れたで」(診断+安心)→「お水も飲んで」(回復サイン)→「みんなの元気玉、届いたで📣」(視聴者への感謝、ドラゴンボール元ネタで前作のコメント主に向けた一言)→「まだ療養中やけど、ボクは大丈夫やで」(締め)。**「みんなの元気玉、届いたで」のようにコメントしてくれた視聴者に直接感謝を伝える一言は、連載2話目以降で使える強力なテクニック**として記録。

**第2話のオーディエンス・いいねタイミング**:フォロワー以外67.9%・女性75.9%(第1話とほぼ同水準)、45-64歳合計66.7%でコア層集中も継続。いいねされたタイミングのグラフは**動画終了直前(18秒)に最大の山**があり、感謝・安心の結末部分が一番強く感情を動かしたことを示す(序盤のフックより結末が効くのはこのジャンル特有)。キャプションも「【ご報告】たくさんのご心配、ありがとうございました」とテロップの感謝トーンと一貫させており、この一貫性もコメント率の高さに寄与したと考えられる。

- **狙って作れるネタではない**。起きた時に最優先でドキュメントする「制作方針」として扱う
- 強さの理由:①演出ではない本物の緊張感、②「元気がない→診断→回復」の連載構造が続きを追わせる、③同じ境遇の介護・介護犬飼い主というコア層に強く刺さる(共感・自分ごと化)
- 次に健康トラブルが起きた際は、①不安な様子を正直に投稿、②経過・診断の報告、③回復の報告、の3部構成を意識して記録する
- 「全力系」が新規リーチの柱なら、こちらは既存フォロワーとの絆を最も深める柱。ただし乱用・誇張は信頼を損なうため、あくまで実際に起きたことを誠実に伝える範囲で

## 使える型・フォーマットのメモ

- **「他の飼い主さんに教えてもらった」型**:情報交換コミュニティが働き、コメントが伸びやすい(さくらの参考投稿で実証)
- **疑問形フック→動画内で答えを見せる→保存CTA**:保存されるコンテンツの基本構造
- **冒頭にフォロー訴求を置かない**:スキップ率が悪化する。CTAは動画の最後に置く
- **開始0.5秒以内に強いビジュアル(あおむけで手足を広げるポーズ等)**:いいねの初速を作る
- **ストーリーズでの投稿予告+投票**:リールの初速エンゲージメントとネタのリサーチを兼ねられる
- **「出た、◯◯」のような短い言い切り型フック+全力の動き**:アカウント史上最高の結果。最終値(数日後):閲覧3,766(アカウント平均の約2.5倍)/プロフィール訪問96/フォロー19(**転換率19.8%、他投稿より高い**)/保存9/コメント18(コメント率0.6%高)/再投稿3/フォロワー以外80%。リールタブ44.8%・発見14.7%など配信元の比率も時間が経っても安定しており、一時的なバズでなく継続的に評価されている。ワンコが全力で何かする瞬間(服を着て跳ねる等)は車椅子ジャンルを超えて刺さる可能性が高い。年齢層はコアの45〜64歳に加えて25-34歳(17%台)まで広がり、他の投稿より若年層への到達が強い。性別は女性59.1%・男性40.9%で、やや女性寄り(他投稿でも共感・いたわり系の言葉選びが効きやすい可能性)。今後積極的に狙いたい型・再現性の検証を優先

## 表情リスト型(ランキング・まとめフォーマット、2026年10月 追加・検討中)

参考アカウントの「わんこの気持ち◯選」「表情でわかる気持ち」のような、数字ラベル+項目を並べるまとめ投稿を見て検討。

**採用理由(既存ルールとの整合性)**:
- 8章の原則「過去素材の切り抜きを繋ぐ形式(ランキング・成長記録)は撮影負荷が低く、保存されやすい」に合致
- 「表情」を切り口にすれば、新しいシーンを撮る必要がなく、**今ある限られた撮影シーン(起きた・寝てる・食べてる・圧迫排尿)の中から表情違いを拾うだけ**で成立する → 「撮影シーンが限られている」問題への解決策になる
- CTA方針の「ランキング・ノウハウ性がある回→保存」とも一致

**企画案「ムギの表情8選」**

| No | 表情 | 撮れる場面 |
|---|---|---|
| 01 | 寝起きのぼんやり顔 | 朝起きた直後 |
| 02 | ごはん待ちの集中顔 | 朝ごはん前 |
| 03 | おやつの袋の音を聞いた顔 | おやつタイム |
| 04 | 車椅子を見た瞬間の顔 | 車椅子を出す時 |
| 05 | マッサージ中のとろけ顔 | ケアの時間 |
| 06 | 名前を呼ばれた時の「ん?」顔 | いつでも |
| 07 | 圧迫排尿前の身構え顔 | ケアの時間 |
| 08 | 飼い主が帰宅した時の顔 | 夕方 |

**フォーマットの選択肢**:
- **Reel版**:各表情を1〜1.5秒のクリップでテンポよく繋ぐ(8個×1.2秒=約10秒+オープニング+CTA)
- **フィード・カルーセル版**(参考画像と同じ形式):静止画8枚。動画編集が不要で、撮影〜投稿までが一番軽い。「本日のムギ」と同じく月水金のメイン制作を圧迫しない運用ができる

**守ること**:
- 数字ラベル(「01」「寝起きのぼんやり顔」)は**事実・ラベル枠(白文字+黒フチ)**を使う。ムギのセリフ用のピンクの縁と混在させない。各カットの最後にムギの心の声を1言添えるなら、そこだけピンクの縁にする
- どちらの形式にするか、撮ってみてから決めてもよい

## 参考フォーマット集(他アカウント研究、2026年10月)

「うちのこ手帖」系アカウントのまとめ投稿(数字ラベル+項目を並べるカルーセル)を研究し、4タイプに分類した。

| タイプ | 内容の傾向 | ムギミルクとの相性 |
|---|---|---|
| ① 気持ち読み解き系 | 鳴き方・耳・しっぽ・表情で気持ちを当てる(例:「鳴き方で読み解く気持ち8選」「耳の向きでわかる気持ち」) | 表情リスト型(上記)で応用中 |
| ② お世話・ルール系 | 家族で揃えたいルール、最高の飼い主とは(例:「家族でそろえたいお世話のルール」) | 汎用的、優先度は中 |
| ③ しつけ・対策チェックリスト系 | 困りごと→今日からできる対策(例:「朝早く起こされるとき試したいこと」「拾い食いを減らしたいとき」) | **◎ ケア系ジャンルと直結** |
| ④ 体の仕草・コンディション観察系 | BCS体型チェック、あくび・お腹を見せる等の仕草の意味(例:「わんこのボディーコンディション」「お腹を見せる時」) | **◎ 車椅子・シニア犬ならではの説得力** |

**③④を優先する理由**:ジャンルの役割分担表の「ケア系=差別化・信頼・コメント率/保存率」にそのまま合致する。他アカウントにはない**車椅子・膵炎・シニア犬という実体験**があるため、同じフォーマットでも独自性が出せる。

**企画案(③④を転用)**
- 「車椅子犬のお出かけ前チェック」(通院・ドライブ前に確認してること5つ)
- 「シニア犬のボディーコンディション、うちはこう見てる」(BCSに加えて、車椅子生活ならではの体型チェックポイント)
- 「膵炎になってから見直したこと」(食事・運動量・体調チェックのルーティンをチェックリスト形式で)
- 「ムギが『しんどい』と伝えてくる仕草」(①の気持ち読み解き系と③の掛け合わせ。膵炎の既往があるため、体調不良のサインを早期発見する切り口は実用性が高く保存されやすい)
