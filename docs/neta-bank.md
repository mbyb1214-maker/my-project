## 台本の型(全企画共通)

```
▼冒頭テロップ(0〜2秒) … 指を止めさせる一言。動画の最初のコマから表示する
▼本編テロップ・セリフ  … ムギの心の声(関西弁・一人称「ボク」)で3〜5行
▼オチ(ラスト)        … ツッコミ or 意外な結末で締める
▼CTA(1つだけ)        … フォロー・コメント・保存のどれか1つに絞る(1.8秒以上表示)
```

## もう一つの型:コールドオープン(No.22)

いちばんいい画が物語の最後にある回は、**結果を先出しして理由を最後に明かす**。

```
0.0〜2.0秒   いちばんうれしそうな動きを先出し(動いているコマから開始)
             テロップは動きに名前をつけるだけ。理由は言わない
2.0秒〜      時系列の頭に戻って本編
ラスト1.5秒  冒頭と同じ動きに戻す + CTA → 最初のコマにつながってループする
```

人が登場する回は「誰に言っているか」をテロップで固定すること。
「あいたかったで」だけでは相手が伝わらない →「お兄さん、あいたかったで」。

## 三つ目の型:レシピ(No.17)

**車椅子・介護と関係ないので、対象が犬飼い全員に広がる**枠。
ベンチマーク先で唯一60万再生まで伸びたジャンル(`docs/benchmark.md` の発見3)。

```
0〜1.5秒   素材から入る(完成品でもよい)
1.5〜3秒   ムギの顔アップ + 理由を隠したひと言
3〜5秒     課題提起(なぜ作るのか)
5〜8秒     材料は◯つだけ / 使う道具
8〜14秒    手順を①②③で
14〜19秒   完成 → ムギが食べる
19〜22秒   保存方法
22〜25秒   詳しいことはキャプションに
25〜27秒   保存して作ってみてな ← CTAは必ず【保存】
```

守ること:
- **セリフは飼い主の声**(関西弁)。この型だけムギの心の声ではない
- 本編のテロップは **7〜8行まで可**(手順があるため)
- 合間に**待ってるムギ**を1〜2カット挟む。情報だけだと飽きる
- **温度や時間は、飼い主が実際にやっている条件をそのまま使う。**
  Claude が一般的な数字を推測で足さない。加熱不足は食中毒につながる
- キャプションに「初めて与える食材は少量から」「持病やアレルギーのある子は獣医に相談」
  「加熱不足は食中毒の原因になる」を必ず入れる
- 試していないことは「試してへん」と書く。知らないことを知らないと書くほうが信用される
