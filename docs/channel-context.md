## 2-1. 先代犬ミルクの扱い(最重要)

チャンネル名の半分はミルクの名前です。亡くなった子の話なので、扱いは慎重に。

守ること:
- **公開してよい範囲に制限はない**(2026年9月21日 飼い主確認)。
  ただし、こちらから「ミルクのネタ」を企画として提案しない方針は維持する。
  出すかどうかは飼い主が決める。
- 触れるときは静かなトーンで。ムギの一人称ギャグと同じテンションに混ぜない。
  テロップは笑わせに行かず、短く、言い切りすぎず。
- 呼び方は「ミルク」。愛称として「ミルちゃん」等を使うかは飼い主の言葉に合わせる。
- 命日・お迎え記念日などに触れる回は、CTAを付けないか「コメントで教えてね」程度に留める。
  その回で数字を狙わない。

絶対にやらないこと:
- ミルクの死を冒頭フックや「オチ」の材料にする。
- 「ミルクの代わりに来た子」「二代目」など、ムギを代替として描く表現。
- ムギとミルクを比べて、どちらかを下げる・優劣をつける。
- 泣かせる目的の演出(悲しい音楽+回想でエンゲージメントを取りに行く作り)。
- 飼い主が言っていない事情(病名・最期の様子など)を想像で書く。

「名前の由来を聞かれたので答えます」のように、**由来を説明する回**は成立する。
その場合もミルクの紹介は事実だけ、短く、ムギの日常に戻して締める。

### 食べもののルール(絶対に守る)

**ムギは膵炎のため、低脂質の食事しかとれません。**

- 食べもの・おやつが出てくる企画は、**必ず低脂質のものだけ**にする
- 高脂質のおやつ(ジャーキー類、チーズ、ボーロ、市販のクッキーなど)を
  ムギが食べる絵・企画は作らない
- レシピ回で紹介するものも低脂質のものに限る(鶏ささみ、鶏むね肉など)
- **「膵炎にはこれがいい」のような効能の断定はしない。**
  「うちはこうしてる」という経験の共有にとどめる
- 迷ったら飼い主に確認する。推測で食材を決めない

### 車椅子8年目という強み

**ベンチマーク先(@corocoro__coronchan)は車椅子介護3年目。ムギミルクは8年目。**
経験の長さそのものが、同じ境遇に入ったばかりの飼い主にとって価値になる。
「8年やってきて分かったこと」は、このアカウントにしか出せない。

プロフィールも「車椅子のミニチュアダックス」で、**これがアカウントの一番の軸**です。
隠すものでも、特別扱いするものでもなく、ムギの日常の前提として扱います。

### 見せ方

- **悲劇にしない。** 悲しい音楽、涙を誘う演出、「頑張っている」のナレーションで
  感動を作りにいかない。ムギは毎日ふつうに生きていて、その日常がおもしろい。
- **隠さない。** 車椅子や後ろ足が映らないように撮る必要はない。映って当たり前。
- **説明しすぎない。** 毎回「後ろ足が動きません」と書かなくてよい。
  プロフィールに書いてあるし、映像を見れば伝わる。
- 病名・経緯・治療については、**飼い主が話すと決めたときだけ**。
  こちらから企画として提案しない。不安を煽る健康情報や断定的な獣医学的アドバイスも書かない。

### 企画を作るときの前提

**次の4つを前提にした企画は、そのままでは撮れません。**

1. 走る・ジャンプする・階段を上る・飛んでくる(後肢麻痺のため)
2. ベッドやソファに自分で上がる(**上がれない。補助が必要**)
3. 高脂質のおやつを食べる(**膵炎のため低脂質のみ**)
4. 水に入る・お風呂を楽しむ(**水が苦手**)

企画を出す前に、ムギの動きと食事でできる形に置き換えること。
分からないときは推測で書かず、飼い主に聞くこと。

**11歳のシニアであることも前提です。** 激しい運動や、負担の大きい「初挑戦」は提案しない。

### 飼い主が使えるスキル・道具

企画を考えるときの手札。ここにあるものは**撮影のハードルが低い**。

| できること | 使いどころ |
|---|---|
| **低温調理機**でささみ・ヨーグルトを作れる | レシピ動画(差別化枠) |
| **炊飯器での低温調理**(むね肉レシピの投稿実績あり) | レシピ動画(**間口が最大**。炊飯器は誰でも持っている) |

**レシピは「間口の広い実用情報」の枠。** 車椅子・介護と無関係なので、
対象が犬飼い全員に広がる。ベンチマーク先で唯一60万再生まで伸びたジャンル
(`docs/benchmark.md` の発見3を参照)。CTAは**保存**にする。

レシピ回の注意:
- **温度・時間は飼い主が実際にやっている条件をそのまま使う。**
  Claude が一般的な数字を推測で入れない。加熱不足は食中毒につながる
- キャプションに「初めて与える食材は少量から」「アレルギーのある子は獣医に相談」を入れる
- 「これを食べれば健康になる」のような効能の断定はしない

### このアカウントにしか出せないもの

**車椅子の子と行ける場所の情報**は、他のどの犬アカウントにも出せない価値です。
1本目のホテル紹介がまさにそれで、「ペットと泊まれる」ではなく
**「車椅子のうちの子でも泊まれた」**と言えるのはここだけ。

- 車椅子でも泊まれた宿
- 車椅子で入れたお店・行けた場所
- 段差・スロープ・芝生の有無など、実際に行って分かったこと

同じ立場の飼い主にとっては保存必至の情報になり、
そうでない人にとっては知らない世界の話として見られます。

## 3. トーン&マナー

### 関西弁の書き方(このチャンネルの声)

よく使う語尾:

| 用途 | 語尾 | 例 |
|---|---|---|
| 断定・報告 | 〜やで / 〜や | 本日、新入りが来たで |
| 説明・理由 | 〜やねん / 〜ねん | この動き出る日は、特別やねん |
| 過去の継続 | 〜ててん / 〜てん | ずーっと待っててん |
| 感想・独り言 | 〜わ / 〜な | 今日は早よ帰るわ |
| 問いかけ | 〜ちゃう? / 〜やろ? | 優しすぎるんちゃう? |
| 否定 | 〜へん / 〜ひん | 名前呼んでも来えへん |

- **盛らない。** 無理に方言を足さず、自然に言う言い方だけ使う。
  「〜どすえ」「〜でんがな」のような作り物の関西弁は使わない。
- 数字・カテゴリ表記(「第3位:」「No.2:」など)は標準語のままでよい。
- ナレーション的な見出し(「【検証】」「Before / After」)も標準語のままでよい。
  関西弁にするのは**ムギの心の声**の部分。

やること:
- 短い文。1テロップ=1息で読める長さ(全角20字前後まで)。
- 犬視点の素直な感情表現(尻尾加速、カミカミ、しっぽ振ります など)。
- オチは「ツッコミ」か「意外な結末」。自分を落として笑わせる。
- 読点少なめ、体言止め・語尾の言い切りでテンポを出す。

やらないこと:
- 人間のビジネス的な言い回し、ハッシュタグの羅列だけのキャプション。
- 過度な擬人化(ムギが人間の知識を語る、金額交渉をする等)。
- 不安を煽る健康情報・断定的な獣医学的アドバイス。
- 他アカウントや他犬種を下げる比較。
- CTAを2つ以上詰め込むこと(下記のCTA方針を参照)。

## 5. 台本の型(全企画共通)

```
▼冒頭テロップ(0〜2秒) … 指を止めさせる一言。動画の最初のコマから表示する
▼本編テロップ・セリフ  … ムギの心の声(関西弁・一人称「ボク」)で3〜5行
▼オチ(ラスト)        … ツッコミ or 意外な結末で締める
▼CTA(1つだけ)        … フォロー・コメント・保存のどれか1つに絞る
```

冒頭フックの型(実装済みの例から):
- 宣言型:「本日、新入りが来ました」
- 対決型:「1,000円のおもちゃ vs ボク」
- 予告型:「※開封の瞬間から目が離せません」
- 順位型:「3位から発表するで。1位は意外やで」

### コールドオープン型(2026年9月に確立)

通常の4ブロックに加えて、**結果を先に見せて理由を最後に明かす**型が使える。
お出迎え・喜び系のように、いちばんいい画が物語の最後にある回で強い。

```
0.0〜2.0秒   いちばんうれしそうな動き(全力ぴょんぴょん)を先出し
             テロップは動きに名前をつけて、理由は言わない
             例:「出た、全力ぴょんぴょん」→「この動き出る日は、特別やねん」
             ※ぴょんぴょんは前足だけで跳ねる動き。後ろ足は床についたまま
2.0秒〜      時系列の頭に戻って本編
ラスト1.5秒  冒頭と同じ動きに戻す + CTA
```

守ること:
- **冒頭は動いているコマから始める。** 溜め(しゃがむ・構える)のコマは切る。
  1コマ目が静止していると、そこで指が止まらない。
- ラストを冒頭と同じ絵に戻すと、最後のコマと最初のコマがつながって**ループする**。
- 冒頭が時系列と食い違うので、視聴者が迷うようなら「ーー その30分前 ーー」を挟む。
- 人が登場する回は、**誰に言っているかをテロップで固定する**。
  例:「あいたかったで」だけでは相手が伝わらない →「お兄さん、あいたかったで」。
- 本編のセリフは通常3〜5行だが、この型は時系列を追うため **6行まで**可。

## 6. CTA方針

1本につき1つだけ。既存のCTAプール(`reel-generator.html` の `CTAS`):
- 「フォローしたら、毎日ボクに会えるで」
- 「コメントで教えてな」
- 「保存して、あとで家族に見せたってな」
- 「いいねしてくれたら、しっぽ振るで」
- 「ほかの動画はプロフィールから見てな」

表示時間は **1.8秒以上**。2行のCTAを1.3秒で出すと読み切れない。

使い分け:
- 新規向けの強い企画 → フォロー
- 共感・あるある系 → コメント
- ランキング・ノウハウ性がある回 → 保存

## 7. ハッシュタグ方針

共通タグ(`BASE_TAGS`)は毎回つける:

```
#ミニチュアダックス #ダックスフンド #犬のいる暮らし #いぬすたぐらむ #犬動画 #関西弁わんこ
```

その上に、企画ごとの固有タグを **2個** 足す(例: `#犬のおもちゃ #開封動画`)。
合計8個に収め、タグの大量羅列はしない。

## 8. 撮影・制作の原則

- 1本は縦型・15〜30秒を基本に、最後まで見られる長さを優先する。
- 反応が薄くても撮る。「薄い反応」そのものがオチになる。
- 過去素材の切り抜きを繋ぐ形式(ランキング・成長記録)は撮影負荷が低く、保存されやすい。
- コメントが集まった回は、回答動画で2本目を作る(1粒で2度おいしい)。
- テロップは**白背景で溶けないように**黒フチか薄い黒帯を入れる。
  玄関の白壁・白い布団に重なる回で特に起きる。
- テロップの位置は画面の上から20〜25%。下部はキャプションとボタンに隠れる。

### 家族以外の人が映る回

- **人間は基本NG。顔を写さない**(2026年9月21日 飼い主確認)。
  画角を下げるか、フレームから外れているカットを選ぶ。家族も含む。
- 勤務中の人(配達員さんなど)が映る回は、**本人に一声かけてから**投稿する。
- 制服・ロゴは、その人が誰なのか(配達の人だ、など)を伝える手がかりになる。
  話の理解に必要ならぼかさず、不要ならぼかす。**内容次第で判断する。**
- 玄関の外を撮る回は、表札・向かいの家・車のナンバーが映っていないか確認する。

## 9. ワークフロー

1. `reel-generator.html` をブラウザで開き、カテゴリを選んでネタを引く
2. 台本をコピーして撮影する
3. 「1週間プランを作る」で5本分をまとめて計画する
4. 新しい企画は `reel-generator.html` の `IDEAS` 配列に追加し、`docs/neta-bank.md` の一覧も更新する

`IDEAS` の1件の書式:

```js
{ cat:"toy", title:"企画タイトル",
  hooks:["冒頭テロップ候補", "..."],
  lines:["セリフ1", "セリフ2", "..."],
  ochi:["オチ候補", "..."],
  memo:"撮影メモ(なぜ伸びるかの理由まで書く)",
  tags:"#固有タグ1 #固有タグ2" },
```
