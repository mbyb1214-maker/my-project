# ベンチマーク記録

参考アカウントの数字と、そこから学んだことを残す場所です。

**1回の観測では何も分かりません。** 同じアカウントを継続して記録することで
「何を変えて、数字がどう動いたか」が見えるようになります。
月1回を目安に更新してください。

## 記録のやり方

`/bench @アカウント名` に、次のスクリーンショットを添えて渡す。

1. **プロフィール画面** — フォロワー数、フォロー中、投稿数、bio、ハイライト
2. **リールタブのグリッド** — スクロールしながら3〜4枚(再生数が見える状態)
3. **気になった投稿の個別画面** — いいね・コメント・リポスト・シェア数

撮影は5分程度。分析と記録は Claude が行う。

## 発見1:途中で跳ねている

古い投稿(旧形式)は **817〜6,811**。新しい投稿は **1万〜60.7万**。
**10〜100倍**に跳ねている。境目でやり方を変えている。

## 発見2:跳ねた要因はシリーズ化とサムネ統一

新しい投稿には、サムネ上部に**シリーズ名のラベル**が入っている。**3つだけ**。

```
コロン家の工夫をお届け      ← 情報・ノウハウ
車椅子わんこのリアル        ← 日常・ルーティン
車椅子の愛犬が教えてくれた  ← 感情・ストーリー
```

サムネのデザインも統一:
- 白い帯に細身の文字、手書き風の下線
- **犬の顔のドアップが必ず入る**
- 明るく白基調

旧形式はハート型の飾り枠でバラバラ。

**重要:動画内のテロップは、ムギミルクと似たピンクの縁取り文字。**
上品なのは**サムネだけ**。つまりカバー画像を別途デザインしている。
