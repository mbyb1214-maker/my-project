# ベンチマーク記録

参考アカウントの数字と、そこから学んだことを残す場所です。

**1回の観測では何も分かりません。** 同じアカウントを継続して記録することで
「何を変えて、数字がどう動いたか」が見えるようになります。
月1回を目安に更新してください。

## 記録のやり方

`/bench @アカウント名` に、次のスクリーンショットを添えて渡す。

1. **プロフィール画面** — フォロワー数、フォロー中、投稿数、bio、ハイライト
2. **リールタブのグリッド** — スクロールしながら3〜4枚(再生数が見える状態)
3. **気になった投稿の個別画面** — いいね・コメント・リポスト・シェア数

撮影は5分程度。分析と記録は Claude が行う。

## 発見1:途中で跳ねている

古い投稿(旧形式)は **817〜6,811**。新しい投稿は **1万〜60.7万**。

## 発見2:跳ねた要因はシリーズ化とサムネ統一

新しい投稿には、サムネ上部に**シリーズ名のラベル**が入っている。**3つだけ**。

```
コロン家の工夫をお届け      ← 情報・ノウハウ
車椅子わんこのリアル        ← 日常・ルーティン
車椅子の愛犬が教えてくれた  ← 感情・ストーリー
```

サムネのデザインも統一:
- 白い帯に細身の文字、手書き風の下線
- **犬の顔のドアップが必ず入る**
- 明るく白基調

旧形式はハート型の飾り枠でバラバラ。

**重要:動画内のテロップは、ムギミルクと似たピンクの縁取り文字。**
上品なのは**サムネだけ**。つまりカバー画像を別途デザインしている。

## 発見3:ジャンル別の再生数の構造

> **2026年9月20日 訂正。** 当初はタイトルから推測して「ホームランは日常・かわいい」と
> 結論づけたが、実物の動画を見たところ **60.7万の正体はレシピ動画**だった。
> 正しくは **「保存される実用情報」がホームラン**。以下は訂正後の内容。

| **実用情報(間口が広い)** | 暑すぎるのでささみ買ってきた(レシピ) | **60.7万** | **保存**される。対象が犬飼い全員 |

| **ルーティン** | 車椅子なしの日 / おでかけ前 / お散歩 | 1万〜4.4万 | **最も再現性が高い** |

### 60.7万「ささみゼリー」の完全な構造(28.79秒)

| 時間 | テロップ | 役割 |
|---|---|---|
| 0-1秒 | 夏が来たのでささみを買ってきました | 素材から入る |
| 2秒 | **理由はひとつ**(犬の顔ドアップ) | **結論を隠す** |
| 3-4秒 | 暑い日のお水飲まない問題を解決するため! | **課題提起** |
| 5-6秒 | 材料はなんと二つだけ | ハードルを下げる |
| 7-13秒 | 作り方は簡単 / 1.ささみを茹でる / 2.お皿に流し入れる / 3.ゼラチンを混ぜ | 手順 |
| 10-11秒 | においにつられた子 | **合間に犬を挟む** |
| 14-17秒 | 冷蔵庫で3時間冷やすだけ! / 完成〜 | 完成 |
| 18-19秒 | うま〜(犬が食べる) | ごほうびの絵 |

| 25-27秒 | 詳しい作り方はキャプションに💫 | **キャプションを読ませる** |
| 28秒 | **保存して作ってみてね** | **CTA=保存** |

学べる点:
1. **課題提起 → 簡単な解決策 → 保存CTA** の型
2. 犬の顔を **2秒・10秒・18秒・ラスト** と規則的に挟み、情報だけで飽きさせない
3. 「詳しい作り方はキャプションに」で滞在時間を伸ばす
4. 冒頭は犬の顔ではなく**素材**から入り、2秒で犬 + 引きのテロップ

### ルーティン型の完全な構造(70.08秒「ドライブルーティン」)

**時刻テロップで進行する。** 時刻が進むこと自体が引きになり、70秒を成立させている。

```
9:18 デートのお誘い    9:23 おしっこ(圧迫排尿)   9:27 うんち
9:28 おむつ            9:28 準備完了               9:35 待ちきれず
9:40 出発              10:11 ご機嫌そう            10:15 急なおさんぽ拒否
10:24 帰宅             10:27 良いお昼に使う        10:30 一息落ち着かせる
10:38 満足ですか?
```

**2層構造になっている:**

| 層 | 内容 | 例 |
|---|---|---|
| 事実 | 時刻テロップ | 9:23 おしっこ |
| 感情 | 飼い主のツッコミ | 全然どいてくれん / はよ行くよ! / (もう帰る) |

事実だけなら記録、ツッコミだけならバラエティ。**両方あるから最後まで見られる。**

**介護の場面を隠していない。** おしっこ・うんち・おむつが時刻とともに淡々と記録され、
悲壮感がゼロ。これが「リアル」の価値になっている。

ラストは質問CTA:「みんなは愛犬と何するのが一番すき?」「ぜひコメントで教えてね」

### ルーティン型・1日まるごと版(29.4秒「車椅子に乗らない日のルーティン」4.4万)

70秒版が「特定の日のイベント」なのに対し、こちらは **1日を29秒に圧縮**。
**16ブロックを29秒**(1ブロック約2秒)で回している。

```
6:00 起床 / 6:04 圧迫排尿 / うんぴ / 6:10 朝ごはん / 7:00 ママの監視員
9:10 察知(もしかして??) / 10:00 車でおでかけ / お買い物 / 12:00 帰宅
13:00 じゃれあいタイム / 16:00 宝探し(ふつうにおやつくれよ)
19:45 圧迫排尿 / 20:00 夜ごはん / 21:00 新入りと遊ぶ
23:00 ママの横でおやすみなさい🌙
→ CTA:フォローして応援してね
```

学べる点:
1. **圧迫排尿が2回、堂々と入っている。** 隠さず、ルーティンの一部として当たり前に置く
2. **タイトルで条件を絞る。** ただの「ルーティン」ではなく「車椅子に**乗らない日の**」。
   「じゃあ乗る日は?」という興味も生む
3. **CTAはフォロー。** 70秒版のコメントCTAと使い分けている。
   ルーティンは「この子の日常をもっと見たい」につながるのでフォローと相性がいい
4. **飼い主の顔は白くぼかしている。** 顔出しせずに成立する

**ムギミルクにそのまま適用できる。** 1日のサイクル(`docs/channel-context.md` 参照)に
時刻テロップを付けるだけ。撮影は各場面5秒、特別な企画も外出も不要。
ムギも家では車椅子なし、圧迫排尿1日3回、16-17時にペットショップ。素材が揃っている。

# バズ動画の構造分析(2026年9月21日)

アカウント単位ではなく、**伸びている単発の動画4本**を分解した記録。

| 動画 | 尺 | テロップ | 効いているもの |
|---|---|---|---|
| 扇風機まくら(ダックス) | **6.7秒** | 3枚・小さい | **名付け** |
| Just a little man in his little pants(ダックス) | 12.2秒 | **1枚を12秒固定** | **画のインパクト** |
| 災害映像と寝る犬 | 14.4秒 | ほぼなし | **対比のモンタージュ** |
| 箱の穴から顔を出す猫 | 24.9秒 | **ゼロ** | **フレーミング** |

## 1. 扇風機まくら(6.7秒・テロップ3枚)

```
暑いから → 扇風機まくら🌀 → ちょっと、かたい…
```

扇風機の台に顎を乗せているだけの日常。効いているのは **「扇風機まくら」という命名**。
普通なら「扇風機の前で涼む犬」だが、**まくらと名付けた瞬間に意味が変わる**。
オチの「ちょっと、かたい…」も、まくらと呼んだから成立している。

## 2. Just a little man in his little pants(12.2秒・テロップ1枚)

テロップは1枚だけで12秒間固定。ジーンズを履いた胴長のダックスが歩く、それだけ。
**絵が強ければ言葉はいらない。**
ネタ帳の企画7「パジャマを着たら人間の子どもになった」(1,627ビュー実績)と同じ構造。

## 3. 災害映像と寝る犬(14.4秒)

落雷 → 寝てる犬 → 隕石 → 寝てる犬 → 竜巻 → 寝てる犬 → **ポテチの袋** → 起きる

**対比のモンタージュ。** 世界が終わりかけても起きないのに、袋の音だけで起きる。
4本の中で唯一、フリー素材を組み合わせて編集している。
ネタ帳の企画16「袋の音だけで飛んでくる犬選手権」の完成形。

## 4. 箱の穴から顔を出す猫(24.9秒・テロップゼロ)

25秒間、猫が箱の穴から顔を出すだけ。**箱の穴がフレームになっている**のが発明。
顔だけが切り取られ、次にどんな表情が出るか読めない。カメラは固定。
やったことは**箱に穴を開けただけ**。

## 共通点1:テロップがほぼない

4本とも説明していない。**ムギミルクは真逆で、手順を説明している。**

ただし単純に真似してはいけない。**ジャンルで分ける。**

| ジャンル | テロップ |
|---|---|
| 介護情報・レシピ | **必須**。数字や手順が価値(膵炎回のいいね率25%は情報があってこそ) |
| **日常・かわいい** | **削れる。絵で見せる** |

## 共通点2:1本1アイデア

4本とも、やっていることが1つだけ。
ムギミルクのマッサージ回はブラッシング→毛づや→マッサージと3つ入っており、焦点がぼける。

## 共通点3:短い

6.7 / 12.2 / 14.4 / 24.9秒。平均14.6秒。**作り込みより企画の発明**。

## ムギミルクで使える型

1. **名付けの型** —「全力ぴょんぴょん」はすでに命名済み。6秒・テロップ3枚で1本作れる
   例:ぴょんぴょん → 全力ぴょんぴょん → (オチ)後ろ足、寝てるけどな
2. **廊下まくら** — 8〜11時に廊下で寝ているムギ。顎を乗せている場所に名前をつける
3. **フレーミングの型** — ムギの顔だけが見える「窓」を作る。
   車椅子のフレーム越し / 毛布の隙間 / **床すれすれの高さ**(前足で移動するムギと同じ目線)。
   ムギは低い位置にいる。その高さの映像は他の犬アカウントに少ない
4. **対比の型** — 「名前呼んでも来えへんのに、袋の音では来る」(ネタ帳16番)
