# 投稿ログ

投稿1本ごとの数字と気づきを記録する場所です。
`/kiroku` にインサイトのスクリーンショットを渡すと、ここに追記されます。

**数字は投稿直後ではなく、数日置いてから記録してください。**
閲覧数もオーディエンスの内訳も、投稿後しばらく変化します。

- **日常系は広く浅く、情報系は狭く深く。** いいね率が2.5% vs 25%

| 項目 | 内容 |

| 種類 | **通常リール** |

| 冒頭 | 「膵炎の子、おやつどうしてる?」横書き・**ムギの笑顔アップ** |

| プロフィール訪問 / フォロー | 10 / 0 | |

**ソース:** フィード80.3% / プロフィール12.6% / リールタブ3.4% / 発見2.4% / 検索1.0%
→ **新規経由は5.8%のみ**

**オーディエンス:** フォロワー76.6%、**45歳以上67.2%**(45-54が32.3%、55-64が31.2%)

- **既存フォロワーにしか届いていない**ので、トライアルで新規に当てる価値がある
- この回で**既存フォロワーの年齢層(45歳以上67%)**が判明した
