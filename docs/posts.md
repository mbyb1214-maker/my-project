# 投稿ログ

投稿1本ごとの数字と気づきを記録する場所です。
`/kiroku` にインサイトのスクリーンショットを渡すと、ここに追記されます。

**数字は投稿直後ではなく、数日置いてから記録してください。**
閲覧数もオーディエンスの内訳も、投稿後しばらく変化します。

---

### 確定したこと

- **冒頭2秒がすべてを決める。** 同じトライアル条件で15倍の差が出た(草津175 / 店員さん2,565)
- **縦書きテロップは使わない。** 2秒で7割が離脱した
- **ムギの顔アップでいいねが押される。** 2本ともいいねのピークは1〜2秒
- **既存と新規は別の集団。** 45歳以上が既存67% / 新規37%
- **日常系は広く浅く、情報系は狭く深く。** いいね率が2.5% vs 25%
- **ムギの顔アップは「いいね」を必ず取れる。** 3本連続でピークが冒頭1〜2秒(21% / 21% / 30%)
- **ストーリーズでのリールシェアは効く。** 19:00シェアでストーリーズ経由が18.5%(第2位)
- **鉄則の達成は「質」を保証するが「リーチ」は保証しない。** リーチはテーマの間口で決まる

**予定と結果を並べて見られるようにするため。**

| 日時 | 枠 | 内容 | 型 | CTA | 狙い |
|---|---|---|---|---|---|
| **9/23(水)18:55** | **トライアル** | 膵炎の子のおやつ、どうしてる? | 情報 | コメント | **仮説1(暗転カット)の検証**。通常版は完走率57%・いいね25% |
| 9/25(金)18:55 | 通常 | 車椅子のムギと行く、軽井沢 | おでかけ | 未確認 | — |
| 9/28(月)18:55 | 通常 | 車椅子のムギでも、温泉旅行に(B/Cホテル) | おでかけ情報 | フォロー | 既存(介護層)に届ける。後日トライアルにも出せば**草津175と直接比較**できる |

**水曜のトライアル2本が、情報系と日常系の比較になっている。** どちらが新規に効くかが分かる。

## #5 この顔が見たくて、毎朝やってる(マッサージ)

| 項目 | 内容 |
|---|---|

**速報値(観測日:2026年9月22日 9:47 — 投稿から約15時間)**

| 指標 | 数値 | 評価 |
|---|---|---|
| 閲覧数 | 551(閲覧者393) | 平均900を**下回る** |
| 平均再生時間 | 4秒 / 11.63秒 = **34%** | #4(57%)より**低い** |
| スキップ率 | **71.3%(高)** | #4(48.2%・低)から悪化 |
| **いいね** | **113**(閲覧者の**29%** / いいね率27.0%・高) | **#4に次ぐ高水準** |
| コメント | **0**(0.0%・通常) | CTAは出ていたのに付かず |
| 保存 | 0(0.0%・低) | |
| シェア / 再投稿 | 0.0%(通常) / 0.0%(通常) | |
| フォロー | **0** | |

**ソース:** フィード53.6% / **ストーリーズ18.5%** / リールタブ18.3% / 発見6.9% / プロフィール1.3%

**再生グラフ:** 100% → 約2秒で50%弱 → なだらかに下降 → 11秒で約10%(**急落点なし=暗転を切った効果**)

**いいねのタイミング:** **0.5〜1秒に30%超のピーク**(過去2本の21%を上回る)

**推移グラフ:** アカウント平均(24時間で約900)を大きく下回り、550付近で横ばい

**判定:いいねは過去2位。リーチと完走率は不足。**
- **ストーリーズ18.5%が新しい。** 19:00のストーリーズシェアが第2の流入源として機能した
- **いいねピークが0.5〜1秒に前倒しになった。** 顔アップを冒頭に置いた効果。鉄則1がこれで3本目の一致 → 確定

- **それでもスキップ率71.3%・完走率34%。** 冒頭で「見る理由」が作れていない。
  #4(膵炎)は「自分の子にも関係ある情報」だったが、今回は「ムギがマッサージされている」だけで、
  視聴者側の用事がない。**鉄則を満たすことは質の前提で、リーチはテーマの間口が決める**
- **コメント0。** CTAは表示できていた(暗転で消えてもいない)ので、原因はCTAの見せ方ではなく
  **問いの答えやすさ**。「どこをマッサージされるのが好き?」は自分の犬を思い出す手間がある。
  #4の「みんなは何あげてる?」は今まさに困っている人が答えられたのでコメント5が付いた
- **フォロー0が4本連続。** 「次も見たい理由」がまだ提示できていない(シリーズ化が仮説6)
