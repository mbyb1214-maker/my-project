# ムギミルク リール企画室 🐾

車椅子のミニチュアダックス「ムギ」(@mugimilk0820)のInstagram運用を助けるツール集です。
企画の配分・投稿時刻・CTAのルールは、実測インサイト分析「ムギミルク 30日設計」
(121投稿・2025.08〜2026.08のデータ)に準拠しています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `reel-generator.html` | リール企画・台本ジェネレーター(ブラウザで動くツール本体) |
| `docs/neta-bank.md` | ネタ帳(全企画の一覧と運用ルールのまとめ・閲覧用) |

## 使い方

1. 型を選ぶ(「おまかせ」は月間配分 実用12/日常9/ナラティブ6/お出かけ3 の重み付き)
2. 「🎬 ネタを引く」を押す
3. 企画・冒頭2秒のフック・テロップ・オチ・CTA・投稿時刻・狙う指標が一式出る
4. 「📋 台本をコピー」してメモアプリに貼り、撮影に使う
5. 「📅 1週間プランを作る」で毎日1本×7日の投稿計画をまとめて生成

## 組み込まれている運用ルール(実測より)

- 毎日1本。主力19:00、勝負回のみ12:00
- 冒頭2秒のフックが決まるまで撮らない(スキップ率40%の壁)
- CTAは型で自動決定: 実用=保存 / 日常=二択質問 / ナラティブ=見守り(開放質問は禁止)
- お出かけは場所紹介ではなく「車椅子で入れるかの検証」
- キャプションは50〜200字。タグより本文

## ネタやセリフを追加したいとき

`reel-generator.html` の `IDEAS` 配列に企画を追加してください。
書式は既存の企画と同じです(cat / title / slot / metric / hooks / lines / ochi / cta / memo / tags)。

Claude Code のセッションで「◯◯のネタを追加して」と頼めば追加できます。
「こういう動画を撮ったからセリフを考えて」と動画の内容を伝えるだけでも、
台本を書いてもらえます。
