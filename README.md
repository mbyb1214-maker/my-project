# ムギミルチャンネル / リール企画室 🐾

ミニチュアダックス「ムギ」のInstagramアカウント
**ムギミルチャンネル** の運用を助けるツール集です。
チャンネル名は、ムギと先代犬ミルクの名前から取っています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `reel-generator.html` | リール企画・台本ジェネレーター(ブラウザで動くツール本体) |
| `docs/neta-bank.md` | ネタ帳(全企画の一覧・閲覧用) |
| `docs/channel-context.md` | チャンネルの設定・方針(キャラ設定 / トーン / 柱 / CTA / タグ) |
| `CLAUDE.md` | Claude Code が毎セッション自動で読む要点まとめ |
| `scripts/video-sheet.sh` | 動画をコマ一覧の画像に変換(Claude が動画を読むために使う) |
| `.claude/commands/` | スラッシュコマンド3つ(下記) |

## 使い方

1. カテゴリを選ぶ(「おまかせ」でもOK)
2. 「🎬 ネタを引く」を押す
3. 企画・冒頭フック・セリフ(テロップ)・オチ・撮影メモ・ハッシュタグが一式出る
4. 「📋 台本をコピー」してメモアプリに貼り、撮影に使う
5. 「📅 1週間プランを作る」で5本分の投稿計画をまとめて生成

## Claude Code のスラッシュコマンド

Claude Code のセッションで、次の3つが使えます。

| コマンド | 使う場面 | 例 |
|---|---|---|
| `/neta` | 何を撮るか決まらないとき | `/neta 今週トリミング。雨続きで散歩に行けてない` |
| `/daihon` | 撮ったけどセリフが思いつかないとき | `/daihon ~/Desktop/mugi.mp4` |
| `/tensaku` | 投稿直前の最終チェック | `/tensaku ~/Desktop/mugi_final.mp4` |

`/daihon` と `/tensaku` は、動画のコマを実際に見てから書きます
(`scripts/video-sheet.sh` が動画を画像一覧に変換します)。
音声は聞けないので、音に関することは確認事項として返ってきます。

ffmpeg が入っていない環境では、スクリプトが自動で `imageio-ffmpeg` を入れます。

## ネタやセリフを追加したいとき

`reel-generator.html` の `IDEAS` 配列に企画を追加してください。
書式は既存の企画と同じです(title / hooks / lines / ochi / memo / tags)。

Claude Code のセッションで「◯◯のネタを追加して」と頼めば追加できます。
「こういう動画を撮ったからセリフを考えて」と動画の内容を伝えるだけでも、
台本を書いてもらえます。
